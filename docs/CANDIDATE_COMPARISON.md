## Selection

The package uses the 1.1.0-candidate repository as its starting point. Its actual source preserves the separate evidence and assessment model and adds controls that have explicit regression tests. The public 1.0.0 candidate's source and tests were inspected as a comparison baseline. This selection is provisional until the 1.2.0 source is recovered and compared.

The separate uploaded `engine.py` labeled `1.0.0-candidate` in earlier work is recorded in the source inventory as a supplemental artifact. It is not relabeled as 1.2.0.
